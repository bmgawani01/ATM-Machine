# ATM Banking System

A Java-based desktop banking application built with **Java Swing** and **MySQL**. The system provides a structured account-opening process where users enter personal details, select an account type and banking services, and receive generated card and PIN details.

## Problem It Solves

Traditional manual account-opening processes can be **time-consuming, repetitive, and prone to data-entry errors**. This project aims to simplify and digitize the process by providing a centralized application for capturing customer information, generating account credentials, and storing registration data in a database.

## Key Features

* Multi-step customer registration
* Personal information collection
* Account type selection
* Automatic card number and PIN generation
* Selection of banking services such as:

  * ATM Card
  * Internet Banking
  * Mobile Banking
  * Email Alerts
  * Cheque Book
  * E-Statements
* MySQL database integration
* Java Swing graphical user interface
* Validation of required information

## Technologies Used

* **Java**
* **Java Swing / AWT**
* **MySQL**
* **JDBC**
* **JCalendar**

## Learning Objectives

This project was developed to strengthen practical skills in **Java programming, GUI development, event handling, database connectivity, SQL, problem-solving, and application design**.

## Project Focus

The project demonstrates how programming can be used to investigate a real-world administrative problem and develop a practical digital solution that improves the efficiency and organization of banking account registration.
